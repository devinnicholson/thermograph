# Support

Thermograph is maintained as research software for a bounded mathematical
domain. Public support is provided through GitHub issues on a best-effort basis.

Use the bug template for reproducible implementation failures and the
mathematical-correctness template for comparison, canonicalization, identity,
or thermograph discrepancies. Include the smallest explicit game, the named
resource profile, the exact crate commit or version, and all commands needed to
reproduce the result.

The project can support:

- installation and documented public APIs;
- finite normal-play comparison and canonicalization within named profiles;
- identity-format and cross-runtime conformance questions; and
- reproducible numerical-thermography discrepancies.

Ruleset adapters, legality, reachability, chess move generation, experimental
search infrastructure, and unpublished Partizan research artifacts belong in
their respective repositories. Requests for custom proofs, unbounded analyses,
or support for excluded game domains may be declined.

Security-sensitive reports follow `SECURITY.md` and must not be posted publicly.
